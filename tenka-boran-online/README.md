# 戦国 天下謀乱(オンライン対戦版)

戦国武将が身分を隠して戦う、裏切りと推理の合戦カードゲームです。
友達と最大5人で遊べます。空いた席にはCPUが入ります。

## 遊び方(公開後)

1. サイトを開き、タイトル画面の「友達と遊ぶ」を押す
2. 名前を入れて「部屋を作る」
3. 表示された「招待リンク」をLINEなどで友達に送る(合言葉4文字でも参加できます)
4. 全員そろったら、部屋を作った人(ホスト)が「この顔ぶれで出陣する」

- 友達はアカウント登録なしで、リンクを開くだけで参加できます。
- 他の人の手札や身分はサーバーの中だけにあり、相手の画面には送られません。
- 対戦中に通信が切れた人は、CPUが代わりに打ちます。同じ端末で同じリンクを開き直すと、元の席に戻れます。
- 返事をしないまま一定時間たつと(自分の手番は90秒、受や薬を出すかの確認は30秒)、自動で「出さない/手番を終える」になります。
- 1人でCPUと遊ぶ「出陣する」も、そのまま使えます。

## 公開のしかた(Render の無料プラン)

用意するもの:GitHub のアカウント、Render のアカウント(GitHub でログインできます)。

### 1. GitHub にファイルを置く
1. GitHub で「New repository」を押し、名前を `tenka-boran` などにして作成(Private で大丈夫)
2. 作ったリポジトリの画面で「uploading an existing file」を押す
3. このフォルダの中身(`server.js` `package.json` `render.yaml` `README.md` `.gitignore` `build.js` と `public` フォルダ)を、まとめてドラッグして「Commit changes」
   - `node_modules` フォルダがある場合は、それは入れなくて大丈夫です

### 2. Render で公開する
1. https://render.com にログインし、「New +」→「Blueprint」を選ぶ
2. さきほどのリポジトリを選ぶと、`render.yaml` の設定(無料プラン・Node)が自動で読み込まれるので「Apply」
   - 「Blueprint」が見当たらないときは「New +」→「Web Service」でリポジトリを選び、次のように入れてください
     - Runtime:Node / Build Command:`npm install` / Start Command:`npm start` / Instance Type:Free
3. 数分待つと `https://tenka-boran-xxxx.onrender.com` のようなURLができます。これが遊ぶためのアドレスです

### 無料プランの注意
- 15分間だれもアクセスしないとサーバーが眠ります。次に開いたときは、起きるまで1分ほどかかります。
- サーバーが眠ったり作り直されたりすると、作ってあった部屋は消えます(対戦中なら最初からやり直しになります)。
- いつでもすぐ遊べるようにしたいときは、Render の有料プランにすると眠らなくなります。

## ゲームを更新するとき
Claude で画面やルールを直したら、新しい `public` フォルダの中身を GitHub に上書きでアップロードしてください。
Render が自動で作り直して、数分で新しい版になります。

## 手元のパソコンで試すとき
Node.js(18以上)を入れてから、このフォルダで次を実行します。

```
npm install
npm start
```

ブラウザで http://localhost:3000 を開きます。
